## Run Locally

```bash
# Clone the repo
git clone https://github.com/urmitmahida34/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

---

## Build for Production

```bash
npm run build
```

Output goes to the `dist/` folder.

---

## Deployment

Deployed on **Netlify** with auto-deploy on every push to `main`.

Build settings:
- **Build command:** `npm run build`
- **Publish directory:** `dist`
